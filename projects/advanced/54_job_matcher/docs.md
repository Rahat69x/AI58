## Executive Summary
Semantic resume-to-job matching engine: computes semantic similarity, extracts skill overlap, and ranks candidate fit.

---

## Architectural Capabilities
- Candidate resume parsing
- Job specification requirements parsing
- Semantic cosine similarity calculation via vector embeddings
- Skill overlap & gap matrix
- Fit percentage score (0 - 100%)
- Transparent match explanation breakdown
- Clear disclaimer: does not make final autonomous hiring decisions

---

## Technical Stack & Dependencies
- **Core Languages**: Python, FastAPI
- **Libraries**: Semantic Vector Matcher, TF-IDF Embeddings, Skill Matrix
- **Shared Platform Services**: AI58 Unified AI Engine, Data Engine, Security Layer
