## Executive Summary
AI-assisted generator for personal portfolio sites with themes, live previews, and exportable layouts.

---

## Architectural Capabilities
- Personal info intake
- Project listings & achievements
- Skills matrix & proficiency tags
- Education & certifications
- Experience timeline
- AI-written compelling descriptions
- Theme picker (Modern Dark, Minimalist Light, Cyberpunk)
- Responsive layout generation & live preview
- Exportable static HTML/CSS/JS bundle

---

## Technical Stack & Dependencies
- **Core Languages**: Python, FastAPI
- **Libraries**: Jinja2, Prompt Engine, Responsive HTML/CSS, JSON Schema
- **Shared Platform Services**: AI58 Unified AI Engine, Data Engine, Security Layer
