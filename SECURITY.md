## Reporting a Vulnerability

The AI58 development team takes security and defensive AI safety seriously.
If you believe you have found a security vulnerability in AI58:

1. **Do not disclose the issue publicly.**
2. Email security details to `security@ai58-platform.internal` or open a private advisory.
3. Include:
   - Module name or endpoint affected
   - Step-by-step reproduction instructions
   - Proof of concept payload if applicable
   - Potential impact evaluation

## Defensive AI Principles & Safety Guardrails
AI58 enforces defensive security across all 58 projects:
- **Project #39 (Security Vulnerability Finder)** is strictly bound to authorized defensive scanning.
- **Project #56 (Healthcare Symptom Checker)** provides research/educational categorization with mandatory clinical disclaimers and explicitly forbids medical diagnostic claims.
- **Project #58 (Financial Literacy Guide)** provides financial education only, explicitly prohibiting personalized regulated investment advice.
- **Project #51 (Disaster Relief Coordinator)** enforces human-in-the-loop validation for all decision pipelines.
- **Private Data Encryption**: User session outputs, mood journals, and passwords use modern cryptographic hashing and token signing.
